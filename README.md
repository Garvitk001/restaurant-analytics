# Global Restaurant Analytics Dashboard 🍽️

**Cognifyz Data Science Internship Project**

An interactive, enterprise-grade data visualization and machine learning dashboard built with Streamlit. This application analyzes global restaurant data to uncover business insights, customer preferences, and predictive metrics.

## 🚀 Live Demo
https://restaurantanalytics.streamlit.app/

## 📊 Project Structure

### 🏢 Level 1: Global Overview
* **Geospatial Analysis:** Interactive global mapping of restaurant locations.
* **Data Integrity:** Missing value handling and data type inspection.
* **Categorical Distribution:** Breakdown of top cities and cuisines.

### 📈 Level 2: Business Insights
* **Service Availability:** Impact of Table Booking and Online Delivery on ratings.
* **Price Range Analytics:** Identifying the most common price tiers and elite rating colors.
* **Feature Engineering:** Encoding categorical text into machine-learning-ready numeric data.

### 🤖 Level 3: AI & Visualizations
* **Predictive Modeling:** Comparison of Linear Regression, Decision Trees, and Random Forest models. Includes a live AI Predictor Engine.
* **Customer Preferences:** Analysis of popular vs. elite cuisines.
* **Interactive Visual Explorer:** Dynamic charts allowing users to filter distributions and compare geographic impact.

## 🛠️ Tech Stack
* **Frontend:** Streamlit
* **Data Manipulation:** Pandas
* **Data Visualization:** Plotly Express & Plotly Graph Objects
* **Machine Learning:** Scikit-Learn
